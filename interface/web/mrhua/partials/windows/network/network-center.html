💡 P2P与广域网通信的区别
广域网通信（MQTT）：轻量级即时消息，适合聊天、通知、实时消息，中心化架构（MQTT Broker）。
P2P去中心化网络：重量级分布式存储和计算，适合资产数据共享、分布式扫描，去中心化架构（DHT）。
两者定位不同，现阶段独立运行，未来可考虑整合。
