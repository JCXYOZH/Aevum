# ADR 0002：记忆模型

## 决定

当前运行时的“记忆”分为两类：纯内存中继里的短期会话上下文，以及 Libertas 数据目录里的持久化账号、订阅与通知状态。中继重启即清空，不做数据库迁移；需要长期保存的内容必须显式写入对应的 SQLite 库或配置文件。

## 边界

- `apps/relay` 的会话、分片和房间成员只在内存。
- `loop.db` 保存订阅、来源、墙和审计，不和 `users.db` 混表。
- `mail.json`、`loop.key`、`loop.pepper` 只在数据目录，不进 Git。

## 后果

任何“记住”的需求先问：这是会话上下文，还是需要跨重启的持久状态。前者留在中继，后者走领域模块。
