# Fortuna 架构

Fortuna 是内核方向，目录按启动、架构、核心、内存、调度、文件系统、网络、沙箱拆分。`boot/` 保留链接脚本和加载器，`core/` 放中断、分页、调度、打印与异常，`arch/` 按 x86、ARM、RISC-V 分文件。

当前状态是骨架与设计验证，不是可直接替换生产内核的完整实现。任何对外能力先经过单元测试和接口冻结，再进入站点或安装包。
## 与当前运行时的关系

Fortuna 不参与 Web 展示与订阅链路。它的价值是把内核边界先在目录和测试里固定下来，等调度、分页和串口协议稳定后，再决定是否接入 QEMU 演示。当前排查页面或模型问题时，不需要从 Fortuna 开始。
