# 术语表

这份文档把项目里的专有名称和通用术语分开写清楚。新读者先看这里，再读代码。

## 通用架构术语

| 术语 | 含义 | 在本仓库的位置 |
| --- | --- | --- |
| 内核（Kernel） | 提供引导、内存、调度、文件系统、网络和沙箱能力的核心运行时 | `src/kernel/` |
| AI 运行时（AI Runtime） | 提供身份、工具、通知、治理、训练和生成能力的核心运行时 | `src/architecture/` |
| 渲染引擎（Render Engine） | 负责数学、模型解析、动画和 WebGL2 渲染的核心运行时 | `engine/` |
| 控制平面（Control Plane） | 负责登记核心运行时、启动和停止进程、汇总状态的独立层 | `control/` |
| 呈现层（Presentation） | 展示页、3D 桌面、桌面壳和旧界面 | `interface/` |
| 中继（Relay） | 只存在于内存中的会话、上下文和分片传输服务 | `control/relay/` |
| 共享层（Shared） | 被多个核心运行时复用的基础代码 | `src/shared/` |

## 项目专有名称

这些名称是项目历史的一部分，保留在包名和目录中；文档首次出现时会给出职责说明。

| 名称 | 说明 |
| --- | --- |
| Aevum | 项目名，社区共建的社区平台 |
| Fortuna | 内核主包，位于 `src/kernel/fortuna/` |
| Libertas | AI 运行时的身份、工具、通知、治理与安全模块，位于 `src/architecture/libertas/` |
| Memoria | AI 运行时的训练、生成与检查点模块，位于 `src/architecture/memoria/` |
| MrHua | 社区里的角色与交互页面名称，位于 `interface/web/mrhua/` |

## 写作约定

- 文档标题和正文优先使用上表中的通用术语，不自造内部词。
- 首次提到专有包名时，同时写出它的职责和代码位置。
- 目录名、包名、命令和路径保持英文原样；解释用中文。
- 一个概念只用一个主词，不在同一篇文档里混用多个说法。
