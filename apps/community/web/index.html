这是什么

社区共建的项目，代码以 MPL-2.0 开源。三个方向共用一个仓库，各自推进、互不阻塞；这个页面是它的显示层——内核只产生状态与错误码，桌面只做可操作的事，说明留在这里。

  • fortuna 内核

    src/fortuna

    从实模式起步的 x86 引导、内核入口、内存、调度与文件系统，用 C 写；引导程序、链接脚本和串口帧都自己动手。内核在 QEMU 里跑通后，把 80×25 文本屏推到这块页面。

  • libertas 安全

    src/libertas

    扫描、蜜罐、取证、响应；工具打成镜像按需运行。身份、子用户、会话与数据作用域也归在这里，先做本机隔离，再谈平台化调度。

  • memoria 记忆

    src/memoria

    记忆层、知识与检索；把讨论、工具产出和训练记录沉淀成可检索的长期记忆。模型在仓库外重新训练：1,352,744 参数、3,000 词表，权重不进仓库。

创造高于消费，心法高于功能，自由高于归属。

桌面是程序，不是另一个展示页

3D 桌面先渲染窗口、启动项和状态，再把角色模型交给引擎；MrHua、订阅、内核实况和中继都在桌面里打开，不用为同一个入口再做一个页面。下面这块只说明边界，操作留在桌面里。

  • 3D 桌面 入口

    apps/community/web/desktop.html

    窗口、启动项、场景与角色分两段加载：功能先出来，模型随后进场，避免大文件把页面卡住。浏览器和以后的桌面外壳打开的是同一份页面。

  • MrHua 程序

    apps/community/web/mrhua

    3D 桌面里的一个程序，不是独立页面。身份、治理、广域网和模型对话按角色权限接入；没有后端能力的启动项先不摆样式，避免点开是空的。

  • 订阅 原生窗口

    js/desktop/panels/subscribe.js

    订阅走桌面原生窗口，不再嵌入一层网页。同一套样式只维护一份，避免“桌面里一个样、网页里另一个样”。

  • 角色模型 引擎

    engine/assets/models

    VRM 主角色与 PMX 引导角色由引擎自己的解析器加载；模型路径从配置进，权重和人物资产不塞进仓库。低配时先只加载一个角色，另一个按需再进场。

同一件事只留一个入口：桌面负责操作，展示页负责说清楚。

模型一周期怎么走

Memoria 的前向主链按代码里的真实顺序写，不套用现成架构的名字。训练、生成和检查点在外围，下面只列一个周期的主路径。

  2. 02

    门控阀

    已实现

    • Q / K / V 三路门控混合，控制写入强度

  3. 03

  4. 04

    已实现

内核实况 · 实时

当前内核是 32 位裸机的三自由度平面机械臂，把 80×25 VGA 的文本单元按差量帧经 COM1 送出，串口桥接再转成 WebSocket。这里画的是真实帧；没有帧时画布保持空白，不填演示数据。

  • proc1 控制

    apps/console/kernel/robot/kernel.c

    算三自由度平面臂的关节量：雅可比伪逆、阻尼、零空间投影和目标速度前馈。目标轨迹故意有一段超出可达半径，用来看最小范数解怎么避开奇异构型。

  • proc2 渲染

    apps/console/kernel/robot/kernel.c

    每帧在影子显存里画 ASCII 机械臂、目标点、轨迹和右侧数值面板，再整块搬到 VGA 文本显存；两个进程按 1:1 协作切换。

  • COM1 帧

    A5 5A 01 COUNT [row col ch attr] CRC

    只发变化过的 80×25 文本单元，不重发整屏。桌面窗口和展示页都通过同一个串口桥接读帧；没有桥接时不伪造画面。
