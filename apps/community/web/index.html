ARCHITECTURE / 一模块一文件

三个模块，承担三种工作

C++ 迁移不是把 Python 文件改个后缀。每个模块有自己的头文件、实现和保存/加载入口；前向链固定，注释写在代码里。

01

GATE / 门控

Gated Valve门控写入

把嵌入后的 token 向量按门控权重写入主路径。它决定这一步有多少信息进入循环，而不是让所有维度等权通过。

src/gated_valve.cpp
02

CHAIN / 循环

Chain Unit × 3三路循环

三个单元共享同一套前向契约，每个单元后面接一个 Tri-Balancer。循环次数由 --cycles 控制，不是写死的固定层数。

src/chain_unit.cpp · src/tri_balancer.cpp
03

MEMORY / 输出

Strata Memory分层记忆

在循环之后汇总 Q / K / V，做加权融合与 V 正则，再由输出层给出下一个 token 的 logits。断点续训会逐项比对词表，避免 token id 悄悄错位。

src/strata_memory.cpp · src/model.cpp

代码阅读顺序：docs/migration.md → docs/formulas.md → include/memoria/model.h → src/model.cpp。

STATE / 按仓库事实写

现在做到哪一步

这里不写“已上线”这种口号。能跑的说能跑，没验收的说没验收；数字来自本机真实运行记录。

  1. P0结构迁移

    15 个 C++ 模块，一模块一文件

    模型、训练器、文本处理器、检查点、生成器和模块保存/加载都已落地；Python 参考实现只读，不复制进仓库。

    已落地
  2. P1训练链

    GPU 训练，断点续训，伪装检查点都能读

    一次 3,000 行小语料的真实运行：8 个 epoch、424 步、train loss 6.25653 → 3.76544。它只证明链路能跑，不证明算法有效。

    已跑通
  3. P2桌面壳

    多窗口 + 启动台 + 组件化

    内核、训练、中继、错误码各有窗口；CSS/JS 按组件拆开。原展示长页保留成启动项，不删。

    已落地
